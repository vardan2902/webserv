About

This server is a 42 school project implementing a subset of the HTTP/1.1 protocol.

Architecture

  • EventLoop – epoll-based multiplexed I/O
  • RequestParser – parses raw HTTP/1.1 requests
  • Router – longest-prefix location matching
  • ResponseManager – serves static files or dispatches CGI
  • CgiHandler – fork/exec with environment setup per CGI/1.1

Supported directives
